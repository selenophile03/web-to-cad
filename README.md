# Parametric CNC Coaster Creator

A lightweight, purely frontend Web-to-CAD automation application that calculates vector coordinates dynamically and prints machine-ready `.dxf` physical blueprints directly inside the browser.

## 🚀 Key Features
* **Zero Backend Architecture:** Client-side vector processing speeds up generation with zero server overhead.
* **Parametric Dimensions:** Dynamically adjust sizes, fillet corner geometry tolerances, and vector layer structures via a simple control panel dashboard.
* **Laser Ready Output:** Segregates geometries into dedicated industrial machine CAD layers (`Outer_Cut` and `Inner_Engrave`).

## 🛠️ Tech Stack
* **Frontend:** HTML5, Tailwind CSS
